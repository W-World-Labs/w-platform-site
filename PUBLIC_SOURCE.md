# Public source distribution

This is the original bilingual static website, unified project console and
product-landing source, with the existing business/API assertions retained.
It is not a replacement marketing-only implementation. The private source and
its operational configuration/history remain separately preserved.

The root MIT license covers W-owned source and documentation. Original authors
zots0127, kanshan, W Agent and W contributors remain credited. Referenced SDK and
imported template assets retain their own notices in THIRD-PARTY-NOTICES.md; root MIT
does not relicense trademarks, external services or npm dependencies.

## Source and assets

The initial local candidate was produced with the installed w-cli 1.5.21
`github export` command, copying all 690 tracked source files byte for byte.
Public curation removes private Actions/deployment configuration and internal
backend pin values, redacts private operational copy/links while retaining the
framework/comparison UI and its historical snapshot boundary, replaces the private npm SDK resolution with fixed PUBLIC
W-ID SDK package, and removes four unused starter media files. Full comparison,
original private configuration and privacy-scan receipts are retained privately.
No product page, console plane or original business assertion was removed.

All 173 product promotional images are preserved byte for byte in the canonical
product-landings/_images tree: 41 generated key-art PNGs, 22 program-drawn UI
mockups and 110 derived landing JPGs. Every image has a creative sidecar. The
key art contains OpenAI generation-source C2PA metadata, the UI renderer uses
local primitives and illustrative literals, and the JPG derivation reads only
stored art. This is source/metadata consistency evidence, not a validation of
C2PA signatures or account ownership. The former original generation output
folder is unavailable; the project author/generation record and prompts are
preserved, with local absolute paths removed. No third-party stock photo,
user-photo collection, live patient record, model, training data or downloaded
weights are bundled. The second 173-file public image tree was an exact byte
mirror and is now prepared from the canonical tree by existing build/dev/test
entry points; image URLs and the original image assertions stay unchanged.

## Integration and acceptance

Public domain names, client IDs and Radar bootstrap attributes are original
application contracts. They do not grant access to live services or establish
production availability. The browser selects real API paths and keeps the
existing identity, tenant and scoped-token boundaries. Generated example data
and test-only tokens are synthetic. Actual merchant/user/traffic data, private
configuration, credentials and operational automation are not distributed.

The five-component protected reference deployment is honestly unconfigured:
all five slots and fixture schemas remain, but repository/ref/commit/PR/
provenance are null and status is pending. All final-pin requirements remain
and preparation rejects pending pins before checkout. The public CI executes
the original self-contained UI/adapter checks and all other `npm run ci`
assertions, not production reference provisioning or live verification.
Operators can supply independently reviewed public backend pins through
REFERENCE_HERMETIC_PINS_FILE; no fabricated backend is substituted.

Only PUBLIC standard GitHub Actions installs dependencies, browsers and builds
the product for checks. The downloadable artifact contains the complete
reviewed Git source plus COMMIT and SHA256SUMS. Installed dependencies and
compiled bundles are not distributed, so this source-only acceptance does not
establish the license closure of a separately deployed bundle or five services.
